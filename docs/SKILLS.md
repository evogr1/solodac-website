# Skills and plugins installed for SoloDac

Last updated 1 November 2026. Every skill below is committed in this repo under `.claude/skills/<name>/SKILL.md`, so any Claude session opened in an up-to-date copy of this repo can use it. A session on another computer or an old copy will not see them until it pulls `main`.

## Plugins (project scope, in `.claude/settings.json`)

- **claude-code-setup** (Anthropic): recommends hooks, skills, plugins and MCP servers for a codebase.
- **claude-mem**: memory across sessions (search, timeline, saved notes). Sends usage telemetry to PostHog by default.

## Asked for but not installable

- **awesome-free-llm-apis**: a list of links, not a skill. Its `agents/` folder is the list maintainer's own bots and was left out.
- **Strix itself** needs Docker plus an LLM API key or a Strix Cloud account. The skills are installed; running Strix needs that key.

Total: 24 skills and 2 plugins.

## Using them on another computer

1. Pull the latest `main` in your solodac-website folder: `git pull origin main`.
2. Restart Claude Code in that folder. It reads `.claude/skills/` from the repo.
3. To have a skill in every project, copy it to your personal folder, for example `cp -r .claude/skills/design-taste-frontend ~/.claude/skills/` (on Windows: `xcopy /E /I .claude\skills\design-taste-frontend %USERPROFILE%\.claude\skills\design-taste-frontend`).
